ติดตั้งโปรแกรม ครั้งแรกครั้งเดียว
Python 3.10+ (ติ๊ก Add to PATH) · Git · Npcap (ติ๊ก Support loopback traffic)
1
Clone โปรเจกต์ ครั้งแรกครั้งเดียว
cd C:\Project_AI
git clone https://github.com/PatcharaponPhetchoochart/Project-AI-IDS.git
cd Project-AI-IDS
2
ติดตั้ง library ครั้งแรกครั้งเดียว
python -m pip install -r requirements.txt
3
เช็กชื่อ network interface
python system\scripts\list_interfaces.py
ต้องเห็น \Device\NPF_Loopback · ถ้าใช้สาย LAN ให้แก้ config\config.yaml → capture.interfaces จาก "Wi-Fi" เป็น "Ethernet"
4
เทรนโมเดล ครั้งแรกครั้งเดียว
python -m notebook training\train.ipynb
กด Run All → รอจนเซลล์สุดท้ายขึ้น model_path -> ...\system\models\iforest.joblib (~10 วินาที) → ปิดได้
5
รันระบบ PowerShell แบบ Administrator
cd C:\Project_AI\Project-AI-IDS
python run_all.py
รอ ~15 วินาที จนเห็น alert-service พร้อมทำงาน · หน้าต่าง monitor จะเด้งขึ้นมาเอง
6
ping ตัวเอง (เปิด PowerShell อีกหน้าต่าง)
ipconfig                  <- ดู IPv4 Address ของ Wi-Fi
ping 172.20.10.2          <- ใส่ IP ของเครื่องตัวเอง
7
✅ ผ่าน ถ้าขึ้น ALERT ภายใน 1–3 วินาที
 ALERT  15:26:59  172.20.10.2 → 172.20.10.2  ICMP  iface=loopback
        เหตุผล: ICMP echo request (ping) ไม่พบใน traffic ปกติ
และหน้าต่าง monitor มีบรรทัด ICMP สีแดง
8
ปิดระบบ
กด Ctrl+C ในหน้าต่าง run_all.py

ใช้ครั้งต่อไป: ทำแค่ขั้น 5–8 · ไม่ขึ้น ALERT: เช็กว่าทำขั้น 4 แล้ว และ Npcap ติ๊ก loopback · รายละเอียดเพิ่มเติม: README.pdf
